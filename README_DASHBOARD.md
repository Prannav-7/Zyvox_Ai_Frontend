## 🔧 Quick Customizations

### Change Dashboard Title
Edit `src/components/Dashboard.jsx` line ~30:
```javascript
<h1 className="text-5xl font-bold mb-2">
  Your Title <span className="text-emerald-400">Here</span>
</h1>
```

### Update Metric Values
Edit state in `src/components/Dashboard.jsx` line ~65:
```javascript
const [stats, setStats] = useState({
  activeUsers: 1250,        // Change this
  totalInvested: 4850000,   // Change this
  // ... more values
});
```

### Change Colors
Search and replace Tailwind classes:
- `emerald-400` → your color
- `emerald-500` → your color
- `teal-400` → your color
